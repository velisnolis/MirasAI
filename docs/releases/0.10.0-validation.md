# MirasAI 0.10.0 validation

Validated on 2026-09-07. The full `npm run release:prepare` completed successfully,
including repository tests, PHP lint, both CMS builds and the router tarball.

## Regression coverage

The five new suites contribute 127 assertions: shared editorial validation (38),
Joomla translation workflow (56), link repair (19), WPML permalink context (4),
and Joomla renderer context (10). The existing suites also passed.

The final review reproduced an explicit empty or `"0"` plain fulltext incorrectly
copying source text. Both values are now preserved and verified through HTTP
against the installed release package.

## Runtime verification

Private CLI pilots exercised Joomla 6.1.3 and WordPress 7.1 with WPML and
YOOtheme 5.0.43. The installed client plugins were not replaced. The pilots
checked real article/menu associations, SQL persistence and rollback limits,
concurrent calls, recovery of the same target ID, WordPress slugs and language
permalinks. Test content was cleaned up and public language homepages checked.

An isolated clone running Joomla 5.4.5, MySQL 8.4 and YOOtheme 5.0.40 exercised
package installation and HTTP/MCP calls for articles, batches, templates, link
repair, static fallback and explicit publication. Separate real database tests
covered concurrent translation calls, nested-set implicit commits, recovery and
the final link-repair compare-and-swap. The original lab's database and files
matched the initial backups after testing. The clone was stopped afterward.

The exact Joomla 0.10.0 ZIP below was installed using Joomla's native installer.
Fourteen additional HTTP checks passed, including `initialize` reporting 0.10.0,
the guarded preview schema, the plain fulltext fix and a Builder update with
verified translated fallback.

## Limits

The WordPress ZIP was inspected, but not installed on a real WordPress runtime;
its functional code was exercised by the CLI pilot. The router passed its suite
and tarball inspection, without updating the shared local router installation.

Dynamic Builder providers do not have a complete runtime test matrix. The HTTP
host rejects publication without a verified target-language content context;
an explicitly unpublished write may return partial status. Custom fields still
require separate review. Not every real workflow failure phase was injected.
The module test reproduces a partial-persistence failure mode, not the original
reported client exception. The standalone regeneration helper's CAS was not
tested with concurrent database connections; the host link-repair CAS was.

See the [migration notes](./0.10.0.md) before upgrading Joomla callers. Host
Builder rendering does not compile Style CSS; Style compilation remains a
local-router capability.
